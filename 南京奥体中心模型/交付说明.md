# 南京奥体中心体育场

按已确认的沙盘风格完成主体育场。先通过内置 imagegen 生成三视图，再用 Blender 制作独立、无树木的带材质模型，接入地图「河西滨江」分组。模型是适合沙盘的建筑概括，不是测绘级复原。

## 文件

- 效果图：`../南京奥体中心效果图/南京奥体中心体育场-三视图.png`，完整生成提示词在同目录的 `imagegen-prompt.txt`。
- 可编辑母版：`南京奥体中心体育场_分组可编辑_带材质.blend`。石台、看台幕墙、屋盖、红拱、场地、摄影棚按集合分组。
- 网页版：`web/南京奥体中心体育场_网页版.blend`、`web/南京奥体中心体育场_网页版.glb`。
- 内嵌并另附三张 1024×1024 贴图：石材、座椅、草坪；红拱、钢构、屋盖、玻璃、跑道等复用材质。
- 实际模型渲染：`web/南京奥体中心体育场_实模_侧前方.png`、`_正面.png`、`_侧面.png`。这些是 Blender 模型渲染，不是概念图。
- `build_aoti.py` 为可重复运行的生成器，依赖项目内 `../景点建模工具/geometry.py`；安装脚本 `install_web.mjs` 在现有项目中运行。

## 验收

- `npm test`：78 项通过，包括导出面数、内嵌贴图、顶点色、真实屋盖开口、两道拱顶、平整干燥基础、道路及白模避让。
- `npm run build`：通过；保留项目已有的主 JavaScript 包超过 500 kB 提示。
- 浏览器确认新 GLB 实际加载 38,018 三角面；全景、近景、材质和方位可见，控制台无错误或警告。点击从全景以缓动拉近至体育场，既有镜头功能继续使用。
- 既有 13 个景点 GLB、树库 GLB 的 SHA-256 均未变化。去掉新增 POI 后，网页地图数据哈希与新增前完全一致。
- 实际渲染器为 `ANGLE Metal Renderer: Apple M5`，已写入浏览器验收记录；未进行目标设备帧率基准测试，不承诺固定 FPS。
- 验收截图和日志在 `../sandbox-app/artifacts/aoti-integration/`。

## 重建

在项目根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python 南京奥体中心模型/build_aoti.py
node 南京奥体中心模型/install_web.mjs
cd sandbox-app
npm test
npm run build
```

网页预览：<http://127.0.0.1:5173/?landmark=aoti>。
