# 中华门模型

无树木微缩建筑概念模型，最终 GLB 为 38,780 个三角面，网页等比缩放 0.38。

- 中华门_分组可编辑_带材质.blend：基础、主体、屋顶/城墙、门窗、栏杆分组；贴图打包，含三台相机及摄影棚。
- web/中华门_网页版.blend：合并网页模型，附烘焙顶点 AO。
- web/中华门_网页版.glb：包含材质、内嵌贴图和顶点阴影；不依赖外部文件。
- web/ 中三张“实模”PNG：Blender 实际模型渲染，包括侧前方、正面、侧面。
- ../中华门效果图/：内置 imagegen 生成的效果图及完整提示词。
- ../景点建模工具/：共用生成源码和详细交付说明。源码也已存入 Blender 文本数据块。

重新生成：从本目录运行

    /Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python build_zhonghua.py

坐标：Blender Z-up、正面 -Y；glTF Y-up、正面 +Z。COLOR_0 为接触阴影，网页加载时应保留，不应再重复烘焙到颜色贴图中。

中华门表现四道真实门洞、三重院落与 27 处藏兵洞。网页地理锚点不变，模型按两侧城墙轴线绕网页 Y 轴旋转 -0.3437929796 rad（约 -19.6979°），相对锚点偏移 [1.8202913, 0, -3.8261449]，两个接头对齐并保留与南侧大报恩塔的间隔。
