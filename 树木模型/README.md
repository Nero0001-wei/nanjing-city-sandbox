# 南京沙盘微缩景观树 v2

`树木_分组可编辑.blend` 是按树种排列的可编辑母版；`web/树木_网页版.blend` 的各树种都位于原点，供实例化使用。GLB 使用 Y-up、树脚原点，包含 7 种树形的普通版和紧凑版；普通版每棵 390 三角面，紧凑版每棵 198 三角面，共用一个材质并保留顶点色及树冠自定义法线。

`tree_shapes.py` 生成分叉树干及不对称叶簇；`build_trees.py` 完成导出、实模预览、实际 GLB 面数统计、网页资源复制与缓存键更新。需要 Blender 5.2。

## 2026-11-02 r187 柔光材质

网页树木改用 `MeshPhysicalMaterial` 的 EON 粗糙漫反射（`diffuseRoughness=0.65`），配合本地生成的 PMREM 天空环境光；降低叶簇凹凸幅度、分开控制树皮/叶簇粗糙度，并为细节与大块色差分别设置按像素覆盖淡出的范围。直接与间接 BRDF 使用原生实现，移除旧的包裹漫反射，避免 EON 在背光轮廓处出现亮点。全局柔光、PCF 和地形材质同时更新；没有修改本目录的 Blender 母版或 GLB。

树库更新前后均为 **4,116 面、89,320 字节**，普通/紧凑树 **390/198 面**；实例数 **2,059**、实例三角面 **622,530**、绘制批次 **14** 均未增加。80 项测试与构建通过，Apple M5 / ANGLE Metal 网页验收无错误，模型与地图数据哈希不变。全景、丘陵、正反向近景、两座桥和手机尺寸截图，以及完整底座避让报告位于 `../sandbox-app/artifacts/soft-light-r187/`。

## 2026-10-30 树形与受光更新

用户选择“自然的微缩景观树”。阔叶树由单块椭球改为相互搭接、大小错落的叶簇；柳树使用下垂叶簇，松树保留展开的枝条，雪松改为错落枝层。配色采用鼠尾草绿、灰绿和淡黄绿，减轻树冠底部预先绘制的暗色。

网页的 `src/tree-material.js` 提供有实际光照和阴影参与的柔和漫反射过渡。近看时，程序化的微小颜色与法线变化补充叶簇表面质感；缩小时按像素覆盖逐渐淡出，减少远景颗粒。这里没有自发光、额外贴图、透明叶片或逐帧阴影重算，也没有改变全城灯光。

`src/terrain-profile.js` 暴露已有完整旋转底座的距离，`src/vegetation.js` 根据完整树冠半径调整缩放，并移除底座范围内的一棵旧树。地形高度计算保持原样。景点 GLB、地理锚点、道路、水岸、桥梁摆放和 PCF 阴影设置均未改变。

证据在 `../sandbox-app/artifacts/tree-refresh/`。`before/` 保存原资产、脚本、网页截图；`after/` 保存新版全景、美龄宫近景与反向视角、玄武湖、两座桥、中华门、奥体中心和移动尺寸截图。`comparison.json` 记录准确统计，`preservation.json` 记录未改动资产与数据的哈希校验，以及 86,391 个地形采样点高度差为 0。

- 使用真实 Apple M5 / ANGLE Metal 渲染；新 GLB 返回 200，所有地标资源正常，网页控制台及着色器无错误。
- 对全部 2,059 棵树冠顶点与 14 处景点/桥梁的完整模型底座投影进行检查，未检测到重叠；普通和反向近景均已检查。
- `npm test`：78 项通过。`npm run build`：通过，仍保留既有主包大小提示。

在项目根目录重建：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python 树木模型/build_trees.py
```

在 `sandbox-app/` 中进行浏览器验收：

```sh
node scripts/check-trees.cjs
TREE_BEFORE=1 node scripts/check-trees.cjs
```

对比模式仅在独立测试浏览器中覆盖旧树木响应及旧树木材质，不改写正式资源。旧版中华门旁的一处重叠会在基线报告中保留。早期景观交付记录见 `../景观优化/交付说明.md`。
