# 总统府 · 无树木带材质模型

表现对象：西式白色门楼、三道贯通拱门、中式回廊与接待堂。这是同风格微缩概念模型，不是测绘复原。

- 分组可编辑源文件：总统府_分组可编辑_带材质.blend
- 网页 Blender：web/总统府_网页版.blend
- 最终 GLB：web/总统府_网页版.glb
- 实模渲染：web/总统府_实模_侧前方.png、正面.png、侧面.png
- 统计与 SHA-256：web/web-model-stats.json
- 效果图与完整提示词：../总统府效果图/
- 本次采用内置 imagegen 生成效果图，再用 Blender 5.2.1 LTS 建模、赋材质、烘焙顶点 AO 和导出。

最终 GLB：36,674 三角面；2,677,408 字节；12 个材质；4 张内嵌贴图。原占位模型为 2,414 面、114,384 字节。GLB 使用索引网格，保留 COLOR_0 顶点明暗；玻璃材质使用不透明浅色表面，避免多层透明排序开销。

Blender 为 Z-up、正面 -Y，GLB 为 Y-up、正面 +Z，底部原点。网页保留原地理锚点，等比缩放 0.39，无额外偏移。01–05 为建筑分组，06 为摄影棚；贴图已打包，摄影棚不会导出至 GLB。

重建：保留上级“景点建模工具”目录及本目录的 web/贴图，在 Blender 后台运行 build_presidential.py；追加 -- --geometry-only 可只核查网格。共用生成器 build_landmark.py、old_city_landmarks.py 与 geometry.py 已随项目保存，并嵌入 Blender 文本数据。

门楼三道拱洞用真实几何开孔，GLB 射线检查确认可贯通；匾额采用从右向左阅读的“總統府”。匾额贴面与背板分离，避免闪烁。
