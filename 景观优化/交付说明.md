# 地形、白模与低面树木交付

日期：2026-10-30。本轮修改本地 Three.js 沙盘，网页地址为 http://127.0.0.1:5173/ 。

## 地形

在既有紫金山与狮子山以外，加入雨花台、菊花台、五台山、清凉山、古林公园丘陵、北极阁、九华山、富贵山、红山、幕府山南麓，共 10 处低缓起伏。位置沿用项目缓存 OSM 的坐标投影；中心点、源要素编号与艺术化高度在 `sandbox-app/src/terrain-hills.js`。幕府山只表现当前画幅内的南麓。

这些高度和山体宽度用于沙盘视觉概括，不是 DEM 或测绘海拔。北极阁的山岗结合现有鸡鸣寺、紫峰的平整底座作了过渡；原来的 14 处地理锚点和所有景点摆放参数没有修改。

整个地面改用连续网格。平地采用源地图 6 像素网格，丘陵区域加密到 1.5 像素，共 107,402 个三角面。加密与稀疏网格的交界都在平面区域，回归测试逐边验证不存在坡面接缝。地形高度同时用于道路、城墙、铺地、建筑基础和植被落点。山坡上的白模保持水平屋顶，基础沿坡面下伸；公园与街区地面细分后贴合山坡。

保留原有水岸、玄武湖五洲、水面和主跨高度；所有景点的完整底座、中华门连接、博物院城墙避让以及两座桥的落岸检查通过。

## 白模

真实 OSM 建筑轮廓由 10,000 栋增加到 11,500 栋；概括组团由 600 栋调整为 613 栋。总计 **10,600 → 12,113 栋**，增加 1,513 栋（约 14.3%）。真实轮廓不做横向放大，估算高度的来源继续保留。

`prepare-buildings.mjs` 与 `prepare-urban.py` 现在都避让长江大桥的完整模型范围。后者直接读取 `BRIDGE_PLACEMENTS`，不复制桥梁端点或角度常量。补充白模不会挤入四座桥头堡的基础；原道路 JSON、连通关系和城墙位置保留。

重建数据（在 `sandbox-app/`）：

```sh
node scripts/prepare-buildings.mjs
.venv-urban/bin/python scripts/prepare-urban.py
```

## Blender 树木

生成器：`树木模型/build_trees.py`。可编辑母版：`树木模型/树木_分组可编辑.blend`。网页 Blender、GLB、统计及真实模型预览在 `树木模型/web/`。运行时使用 `sandbox-app/public/models/trees.glb`，版本与实际导出面数、大小、来源写入 `manifest.json` 的 `vegetation` 字段；生成器同步更新 `src/tree-asset.js` 的内容哈希缓存键。

树冠使用连续、有少量不对称的轮廓、平滑法线和顶点色明暗，不叠加密集叶片。7 种树形各有普通版与街区紧凑版，按种类与细节级别合计 14 个实例化批次；旋转、大小和颜色变化复用同一几何。紧凑版按植被大小选择，不是随镜头切换的动态 LOD。全树库共用 1 个材质，无外部贴图依赖。

| 树形 | 旧普通版 | 新普通版 | 旧紧凑版 | 新紧凑版 |
| --- | ---: | ---: | ---: | ---: |
| 香樟 | 664 | 184 | 184 | 112 |
| 梧桐 | 736 | 184 | 256 | 112 |
| 银杏 | 664 | 184 | 184 | 112 |
| 柳树 | 728 | 184 | 308 | 112 |
| 松树 | 656 | 334 | 236 | 208 |
| 雪松 | 124 | 192 | 124 | 156 |
| 花树 | 764 | 184 | 284 | 112 |

新面数全部读取最终 GLB 的三角形索引计算，而非 Blender 的四边面数。树库共 **2,370 三角面，59,668 字节（59.7 KB）**；单棵最高 334 面，远低于建筑地标预算。旧方案在 JavaScript 内生成树木，没有旧 GLB 文件，不能把旧 GLB 大小写成一个虚构对比值。旧全部树木几何顶点缓冲合计约 1.92 MB，这也不是网络文件大小。

移除了可能穿过山坡的树根切线阴影平面，使用场景中的真实树影与树冠顶点色。保持树冠对道路、建筑、城墙和桥体的避让。

重新生成：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python 树木模型/build_trees.py
```
